# Login JWT

Projeto de autenticação JWT com frontend em HTML/CSS/JavaScript e backend em Node.js.

## Tecnologias utilizadas

### Frontend
- HTML5
- CSS3
- JavaScript (ES6+)
- Fetch API para requisições HTTP

### Backend
- Node.js
- Express.js
- JSON Web Token (JWT)
- CORS
